# 智慧树刷课助手智慧树在线教育平台的 Electron 桌面端自动挂机刷课工具。## 功能特性- 视频自动播放、自动静音- 章节自动切换、自动跳转下一节- 后台运行，不干扰其他窗口操作- Windows 桌面端免安装，解压即用## 下载与安装前往 [Releases 页面](https://github.com/mayuesu/zhihuishu-autoplay/releases) 下载最新版压缩包：1. 下载 `zhihuishu-autoplay-vX.X.X.zip`2. 解压到任意目录（路径不要含中文/空格更稳妥）3. 双击 `启动.bat` 或 `智慧树刷课助手.exe` 运行> 仓库中的 `app.asar` 是应用逻辑包，`启动.bat` 是启动脚本；完整可运行程序请从 Release 下载。## 使用方法1. 打开软件后登录智慧树账号2. 选择要刷的课程3. 软件会自动连续播放视频并切换章节## 免责声明本项目仅供学习交流与技术研究使用，请勿用于违反学校校规校纪、教学纪律或平台用户协议的行为。因使用本工具产生的一切后果由使用者自行承担。## 许可证[MIT](LICENSE)
